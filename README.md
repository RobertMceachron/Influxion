# Influxion VR
**Influxion VR** is a virtual reality simulation aimed at recreating a realistic tsunami, while tracking player location, people saved, and other behavior-based data. Initially started in 2024, it was made for Unreal Engine 5.7 and is confirmed to work on the Quest 2 and 3 head-mounted displays. While Influxion VR includes code, it does not include any assets used, as they are not open sourced. Unfortunately, this includes the water behavior, which used Fluid Flux 3.0. The primary purpose of this code is for others to repurpose preexisting code or further analyze the project's methodology. A fully built EXE with assets included is available upon request only to fellow researchers.
